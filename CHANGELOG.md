# Changelog

All notable changes to this package are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the package uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-04

### Added
- AdMob Mediation Manager window (Tools > AdMob Mediation Manager) with Networks, App Settings and
  Integration Status tabs.
- Install, update, update all and remove the Google Mobile Ads plugin, EDM4U and 18 mediation adapters from OpenUPM.
- Detection of `.unitypackage` adapter installs, migration to packages, and duplicate detection.
- Native Android/iOS SDK versions read from each adapter's EDM4U dependencies file.
- App ID editing with format checks, and Google's sample App IDs.
- `AdUnitIdSet` asset with a test ad unit switch.
- Privacy-safe text report for bug reports.
