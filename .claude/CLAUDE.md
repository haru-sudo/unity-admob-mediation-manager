# Rules for AI agents / AI エージェント向けのルール

This repository's merge rules apply to Claude Code and every other agent. See `.github/CONTRIBUTING.md`.

- Never merge a pull request. Merging is always done by hand by the maintainer.
- Never enable auto-merge, approve a PR, or resolve review threads on the maintainer's behalf.
- Never push to `main` unless the maintainer explicitly tells you to in this session.
- Never force-push to `main` or delete it.
- Do not add `Co-Authored-By` trailers or any other AI attribution to commits; keep AI out of the contributor list.
- Follow `.github/pull_request_template.md` when opening a PR, and leave it for the maintainer to review.
- Commit the `.meta` file for every new file or folder outside dot-folders (this is a Unity package).
- Never commit real App IDs, ad unit IDs or API keys.
